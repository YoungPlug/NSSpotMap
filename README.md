# Споты — карта Нови-Сада и Белграда

Приложение сделано на TypeScript, React, Vite и Leaflet. Для общей карты используется Supabase: споты и фотографии сохраняются в общей базе и появляются у посетителей в реальном времени. Аккаунт посетителям не нужен.

## Запуск

```sh
npm install
npm run dev
```

## Подключение общей карты

1. Создай проект Supabase.
2. Открой файл `supabase/setup.sql` в редакторе кода, скопируй его содержимое целиком, вставь именно SQL-код в Supabase → SQL Editor и нажми **Run**. SQL Editor не принимает путь к файлу.
3. Скопируй `.env.example` в `.env.local` и укажи Project URL и anon/publishable key из настроек API проекта.
4. Перезапусти Vite. При публикации сайта добавь те же две переменные в настройки хостинга.

Используй только anon/publishable key. Service role key нельзя помещать в браузерный код или `.env.local` для Vite.

Без настроек Supabase приложение остаётся в локальном режиме: споты будут видны только в текущем браузере. Любой посетитель подключённой общей карты сможет добавлять публичные споты и фотографии; удаление через сайт не предусмотрено.

## Возможности

- Два города: Нови-Сад и Белград.
- Категории: перила, грань, лестница, скейт-парк, мануал-бокс и другое.
- Добавление фотографии, названия и заметки.
- Обновления новых спотов в реальном времени у всех посетителей.
