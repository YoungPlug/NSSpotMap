# Споты — карта скейт-спотов Сербии

Совместная карта скейт-спотов Нови-Сада и Белграда. Можно отметить точку на карте, выбрать тип препятствия, добавить описание и фотографию. Новые споты сохраняются в Supabase и появляются у других посетителей в реальном времени.

## Возможности

- Карта Нови-Сада и Белграда на OpenStreetMap.
- Категории: перила, грань, лестница, скейт-парк, мануал-бокс и другое.
- Добавление спота нажатием на карту или кнопкой добавления.
- Фотографии, заметки и фильтр по категориям.
- Общая база с обновлениями в реальном времени.
- Адаптивный интерфейс для телефона и компьютера.

## Технологии

- React и TypeScript
- Vite
- Leaflet и React Leaflet
- Supabase Database, Realtime и Storage
- Vercel для публикации



## Публичный доступ и фотографии

В текущей конфигурации посетители могут читать споты, а любой анонимный посетитель может добавлять новые споты и фотографии без входа в аккаунт. Фотографии и заметки общедоступны. Интерфейс сайта не поддерживает редактирование и удаление спотов.

Поддерживаемые типы файлов: JPEG, PNG, WebP и GIF. Максимальный размер одного изображения — 3,5 МБ. Для защиты от спама или добавления модерации потребуется отдельно изменить правила доступа и интерфейс.

На карте есть стартовые точки скейт-парков Нови-Сада и Ушче в Белграде. Их демонстрационные фотографии загружаются с внешних сайтов.
